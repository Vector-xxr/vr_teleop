## 一、技术领域

本发明涉及机器人遥操作与人机交互技术领域，具体涉及一种面向双臂协作机器人的虚拟现实（VR）遥操作方法及系统，尤其涉及基于虚拟骨架的肘部构型约束、路径连续优先的运动生成，以及 VR 交互与本地实时控制相分离的系统架构。

---

## 二、背景技术

现有机器人遥操作系统多采用以下方式之一或其简单组合：

1. **纯末端笛卡尔跟踪**：将操作者手柄位姿直接映射为机器人末端位姿，再经逆运动学求解关节角。该类方法实现简单，但在接近关节限位、奇异位形或工作空间边界时，易出现逆解跳变、肘部构型突变、整臂突然重组等问题，跟手体感差，且不利于长时间稳定作业。

2. **强依赖专用头显应用的封闭方案**：操作端需安装定制 App，部署与版本迭代成本较高，不利于实验室快速验证与产线原型推广。

3. **功能割裂的示教链路**：实时遥操作、精细点动、双臂相对锁定、动作录制回放等能力往往分属不同工具链，难以形成“示教—微调—复现”的统一闭环。

因此，有必要提供一种既能保持仿人手臂构型、又能保证末端跟踪与运动连续，并便于轻量化接入与工程落地的双臂 VR 遥操作技术方案。

---

## 三、发明目的

本发明旨在提供一种双臂 VR 遥操作方法及系统，实现：

1. 在保证末端六维跟踪优先的前提下，通过虚拟骨架约束肘部构型，提升仿人操作性与运动可预期性；
2. 通过路径连续优先策略抑制逆解跳变与肘部突变，提高真机作业安全性与跟手舒适度；
3. 在同一控制栈内集成 VR 遥操作、面板点动、双臂相对锁定及录制回放，形成完整示教工作流；
4. 采用 WebXR 轻量化接入与本地高性能控制分离架构，降低部署成本并保障实时控制确定性。

---

## 四、技术方案

### 4.1 系统总体架构

本系统包括：

- **操作端**：头显浏览器基于 WebXR 采集双手柄位姿、握持及按键状态；
- **桥接服务**：将 WebXR 数据转换为标准网络报文（如 UDP）下发；
- **本地控制节点**：完成位姿映射、虚拟骨架求解、逆运动学、关节参考生成、安全约束与电机级跟踪控制；
- **执行层**：经现场总线（如 CAN）驱动双臂及夹爪，或接入仿真环境进行联调。

操作端与控制端解耦：前端负责交互采集与轻量部署，后端负责低延迟、可确定的运动控制与安全闭环。

### 4.2 基于虚拟骨架的仿人双臂遥操作控制（创新点一）

在常规末端位姿跟踪之外，引入肩–肘–腕虚拟骨架模型：

1. 根据当前肩部位姿与期望腕部位姿，在虚拟骨架上生成肘部目标（包括肘部旋转自由度 φ 及相关几何量）；
2. 逆运动学以末端位置与姿态为**主任务**；
3. 将肘部目标置于任务**零空间**中作为次级目标进行优化，使手臂构型更接近人体习惯，同时避免与末端跟踪发生硬冲突。

相较仅追求末端笛卡尔跟踪的方案，本方法可降低遥操作过程中肘部姿态紊乱与非自然拧转，提升双臂协同作业时的可操控性。

### 4.3 以路径连续性为核心的稳定跟手策略（创新点二）

针对真机遥操作中的逆解跳变、肘部突变、边界附近整臂重组等问题，采用“路径连续优先于单步硬到位”的策略，主要包括：

1. **握持重锚定与相对增量映射**：操作者按住握持键后建立位姿零点，以相对增量驱动机器人，避免绝对位姿硬贴合带来的冲击；
2. **关节指令与肘角指令速率限制**：对目标关节角及肘部 φ 进行连续限速，抑制单周期大幅跳变；
3. **肘部解支路防翻转**：在肘部可行解分支之间禁止突变切换，保持构型连续；
4. **软可达域约束**：在接近伸展极限时平滑处理目标，减少边界冲击；
5. **微小运动抑制**：对手柄抖动与细微扰动进行吸收，避免静止时整臂无意义重组。

上述机制保证操作者意图连续映射为机器人运动，提高长时间作业下的安全性与舒适度。

### 4.4 VR 遥操作与示教微调、动作复现一体化架构（创新点三）

在同一底层控制与硬件接口上，集成多种作业模式：

1. **头显手柄实时遥操作**：双臂跟手、夹爪开合等；
2. **桌面端笛卡尔点动微调**：用于精细位姿调整；
3. **双臂相对位姿锁定（主从协同）**：锁定双臂相对几何关系，实现协同搬运、相对约束作业等；
4. **动作录制与回放复现**：将示教轨迹固化并重复执行。

各模式共用控制栈与安全链路，形成“远程示教—精细调整—轨迹复现”的完整工作闭环，适应产线示教与工艺固化等场景。

### 4.5 基于 WebXR 的轻量化接入与高性能本地控制分离（创新点四）

1. 操作端采用头显浏览器 WebXR 采集位姿，无需依赖专用应用商店分发链路；
2. 经桥接服务以标准协议传输；
3. 运动规划、逆解、安全约束与电机控制在本地 C++ 控制节点完成，保障实时性与确定性。

该架构降低前端部署与迭代成本，同时保留真机级控制性能，适用于实验室验证与产线原型快速部署。

### 4.6 典型工作流程（概括）

1. 系统上电并完成双臂使能与安全自检；
2. 可选执行预置启动轨迹至作业准备位姿；
3. 操作者在头显中打开 WebXR 页面并建立连接；
4. 按住握持键进入跟手状态，松开则保持当前位姿；
5. 需要时切换点动、主从锁定或录制回放模式；
6. 全程由本地安全层对速度、力矩及异常状态进行约束。

## 五、有益效果

1. **仿人构型与末端精度兼顾**：虚拟骨架 + 零空间肘约束，在保证末端跟踪的同时改善手臂形态；
2. **运动更连续、真机更安全**：路径连续策略有效抑制逆解跳变与肘部突变；
3. **工程闭环完整**：遥操作、微调、主从锁定、录回放一体化，便于示教固化与复现；
4. **部署灵活、控制可靠**：WebXR 轻量接入 + 本地实时控制分离，兼顾易用性与性能。

## 六、关键技术点 / 拟保护要点（建议）

1. 一种在 VR 遥操作中基于肩–肘–腕虚拟骨架生成肘部目标、并将肘部置于零空间优化的双臂控制方法；
2. 一种以握持重锚定、关节/肘角限速、防翻支及软可达约束为核心的路径连续跟手方法；
3. 一种在同一控制栈内融合 VR 遥操作、笛卡尔点动、双臂相对锁定与录制回放的一体化系统；
4. 一种 WebXR 轻量化操作端与本地高性能运动控制节点相分离的遥操作系统架构。

## 九、具体实施方式（示例性）

在一种双臂协作机器人实施例中：

1. 左右臂分别接收对应手柄的位姿增量；
2. 控制周期内，由虚拟骨架根据肩部与期望腕部计算肘部 φ 目标；
3. 逆解以腕部位姿误差为主任务，肘部误差在零空间内衰减；
4. 对得到的关节目标施加速率限制后，经关节参考生成器输出给底层跟踪控制器；
5. 当检测到手柄握持释放、通信超时或安全阈值触发时，切换为保持或卸力保护状态。

上述参数（增益、限速、软可达阈值等）可根据机型与任务标定，不构成对保护范围的限定。
