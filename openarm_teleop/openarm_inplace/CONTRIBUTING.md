# 贡献指南

## 发现 Bug？

请通过 [GitHub Issues](https://github.com/enactic/openarm_teleop/issues/new?template=1-bug-report.yml) 提交问题报告。

## 有功能建议？

请通过 [GitHub Issues](https://github.com/enactic/openarm_teleop/issues/new?template=2-feature-request.yml) 提交功能请求。

## 已经写好补丁？

请提交 Pull Request。

提交前请先阅读项目许可证：[LICENSE.txt](LICENSE.txt)。

## 其他讨论

欢迎在 [Discord](https://discord.gg/FsZaZ4z3We) 或 [GitHub Discussions](https://github.com/enactic/openarm_teleop/discussions) 中交流。
