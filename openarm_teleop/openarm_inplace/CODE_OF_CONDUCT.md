# 贡献者行为准则

## 我们的承诺

作为社区成员、贡献者和维护者，我们承诺让每个人都能在免受骚扰的环境中参与本项目。无论年龄、体型、可见或不可见的残障、族裔、性别特征、性别认同和表达、经验水平、教育背景、社会经济地位、国籍、个人外貌、种族、阶层、肤色、宗教、性取向或性别取向如何，每个人都应受到尊重。

我们承诺以开放、友善、多元、包容和健康的方式交流与协作。

## 我们的标准

有助于建设积极社区环境的行为包括：

- 对他人展现同理心和善意。
- 尊重不同意见、观点和经历。
- 给予并坦然接受建设性反馈。
- 在犯错时承担责任，向受影响的人道歉，并从经验中学习。
- 不只考虑个人利益，也关注整个社区的长期健康。

不可接受的行为包括：

- 使用性化语言、图片，或任何形式的性骚扰和不受欢迎的性关注。
- 挑衅、侮辱、贬损性评论，以及人身或政治攻击。
- 公开或私下骚扰他人。
- 未经明确许可公开他人的私人信息，例如住址或邮箱地址。
- 其他在专业环境中可被合理认为不适当的行为。

## 执行责任

社区维护者负责解释并执行可接受行为标准。对于被认定为不适当、威胁性、冒犯性或有害的行为，维护者会采取适当且公平的纠正措施。

维护者有权移除、编辑或拒绝不符合本行为准则的评论、提交、代码、Wiki 编辑、Issue 和其他贡献，并会在适当情况下说明处理原因。

## 适用范围

本行为准则适用于所有社区空间，也适用于个人以官方身份代表社区出现在公共空间时。代表社区的例子包括使用官方邮箱、通过官方社交媒体账号发言，或作为线上/线下活动的指定代表参与活动。

## 举报与处理

滥用、骚扰或其他不可接受行为可以向负责执行的社区维护者举报：

```text
hi_public@reazon.jp
```

所有投诉都会被及时、公正地审查和调查。维护者有义务保护举报人的隐私和安全。

## 执行指引

社区维护者会参考以下社区影响等级，决定违反本准则后的处理方式。

### 1. 纠正

**社区影响**：使用不适当语言，或出现被认为不专业、不受欢迎的行为。

**处理方式**：维护者以私下书面警告的方式说明问题性质，并解释为何该行为不适当。必要时可要求公开道歉。

### 2. 警告

**社区影响**：一次事件或一系列行为构成违规。

**处理方式**：发出警告，并说明后续继续违规会带来的后果。在指定时间内，违规者不得与相关人员互动，包括不得主动联系执行行为准则的维护者；该限制也适用于社区空间和社交媒体等外部渠道。违反限制可能导致临时或永久封禁。

### 3. 临时封禁

**社区影响**：严重违反社区标准，包括持续的不适当行为。

**处理方式**：在指定时间内禁止与社区进行任何形式的公开互动或公开沟通。期间不得公开或私下联系相关人员，包括不得主动联系执行行为准则的维护者。违反限制可能导致永久封禁。

### 4. 永久封禁

**社区影响**：表现出持续违反社区标准的模式，包括长期不当行为、骚扰个人，或攻击、贬损某类群体。

**处理方式**：永久禁止在社区内进行任何公开互动。
